# Modelos de Pedido

5 páginas-modelo criadas na Gestão de Pedidos, prontas a duplicar:

| Modelo | Conteúdo |
|---|---|
| 🧩 MODELO — Visto | Checklist: Passaporte, Fotografia, Seguro, Formulário, Carta, Reserva, Pagamento, Entrega |
| 🧩 MODELO — Bilhete | Dados a preencher antes de enviar bilhete |
| 🧩 MODELO — Hotel | Dados de reserva, check-in/check-out |
| 🧩 MODELO — Empresa (Corporativo) | Checklist de subitens e Requerente |
| 🧩 MODELO — VIP | Checklist de atendimento premium e acompanhamento pós-viagem |

## Limitação

A API do Notion não cria Templates nativos de base de dados (os que aparecem em "+ Novo → escolher modelo"). São páginas normais, marcadas com prefixo 🧩 MODELO, feitas para duplicar.

## Uso

**Opção A (imediata):** duplicar a página-modelo (`⋯ → Duplicate`) ao abrir um pedido desse tipo.

**Opção B (recomendada, 30s por modelo):** converter em Template nativo via `+ Novo → + Novo template`, copiando o conteúdo da página-modelo para dentro do editor de template.
